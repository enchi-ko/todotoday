# Backing up your data — why, and how

Your app now has an **Export backup** and **Import backup**. This note explains
why that matters and what to watch out for.

## Key Concepts

**Where does your data live?** In your case, **in your browser** (a small storage
area the browser gives each website). It's convenient — nothing to set up — but
it has one weakness: it belongs to *that browser on that device*.

**What can make it disappear?**
- Clearing your browser's data / "cookies and site data".
- Using a different browser or a different device (the list won't be there).
- A browser or profile reset.

**A backup is just a copy you control.** "Export backup" writes your tasks to a
file on your computer. That file is *yours* — it survives clearing the browser,
and you can carry it to another device.

**Restoring is the other half.** "Import backup" reads that file back in. Because
files can be edited or damaged, the app **validates** the file first: if it isn't
a proper task list, the app refuses and keeps your current list — so a bad file
can never wipe good data.

**A backup is a snapshot, not a live sync.** Export again after big changes to
keep the file up to date. (There's no automatic sync — a deliberate, simple
choice for now.)

## How This Applies to Your Project

- **Export** lives behind the "Export backup" button — it writes `todotoday-backup.json`.
- **Import** is the "Import backup" button — it **replaces** your current list with the file's contents.
- The file is plain JSON — human-readable, and easy to keep in cloud storage or email to yourself.
- Import validation is covered by tests (a corrupt file is rejected and the list is left alone).

## Quick Reference Card

| Concept | Summary |
|---------|---------|
| Where data lives | In your browser, on this device |
| Risk | Clearing browser data, or switching device |
| Backup | "Export backup" → a file you keep |
| Restore | "Import backup" → replaces your list |
| Safety | A bad file is rejected; your list is untouched |
| Habit | Export again after big changes |
