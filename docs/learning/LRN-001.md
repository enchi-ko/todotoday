# How a software project gets built — the full cycle

You just took an idea ("a shared to-do list for two people") all the way to a
released app. Here's the path you walked, in plain language — so you can
recognise it next time.

## Key Concepts

**An idea is not yet a project.** Before anything is built, the idea is written
down in its own words, then checked back with you. That's your project's
"intent" — the anchor everything else points back to.

**A plan is a promise about *what*, not *how*.** The work is broken into goals
("add a task", "mark it done") and each is given a rough size. The total is kept
under a budget so a cycle doesn't grow forever.

**Requirements are how you know you're done.** Each goal becomes a short list of
"what the app should do" plus **acceptance criteria** — statements like *"given
a task, when I mark it done, then it shows as done"*. These aren't paperwork:
they become the automatic checks that prove the app works.

**Building happens in a copy, then gets merged back.** Work is done on a
separate **branch** (a parallel copy of your project), so the main line stays
safe. When it's verified, the branch is merged in.

**Version control is your infinite undo.** Every change is saved as a snapshot
with a message. You can always go back. A **tag** (like `v0.1.0`) names an
important snapshot — here, your first release.

**Deliver = merge + tag + clean up.** The verified work joins the main line, a
version is named, temporary branches are tidied, and release notes are written.

**Wrap-up closes the loop.** After delivering, you look back: what worked, what
to improve, what you learned. That's this note.

## How This Applies to Your Project

- Your idea is recorded in `docs/intent.md` (INT-001).
- Your first cycle's plan is archived at `docs/sprints/sprint-01/plan-summary.md` (PLN-001).
- Your requirements — the "what it should do" — are in `docs/sprints/sprint-01/reqs.md` (REQ-001 … REQ-005, REQ-101).
- Your app was built on branch `gse/sprint-01/feat/add-task` and merged into `main`.
- Your release is tagged **`v0.1.0`**; the notes are in `docs/sprints/sprint-01/release.md`.
- Your app itself: `app.py` (the server) + `templates/index.html` (the page) + a small database (`tasks.db`).
